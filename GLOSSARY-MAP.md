# Glossary Map

This repo holds independent skills, so it is a multi-context repo: each skill that has vocabulary of
its own gets a glossary beside its `SKILL.md`. Files are created lazily — a skill with no glossary
has not needed one yet.

## Contexts

- [PR review](./skills/pr-review/GLOSSARY.md): reviewing one pull request — legs, findings, verdicts,
  modes and the record

## Relationships

- None yet. Skills are independent; where one depends on another's vocabulary it links to that
  glossary rather than restating it.

## Note on files met in the wild

A project's own glossary lives at its repo root as `GLOSSARY.md`. Before the 2026 rename it was
called `context.md`, and there is **no automatic migration** — when you meet a `context.md` at a
project root, rename it by hand and check nothing still links to the old name.
